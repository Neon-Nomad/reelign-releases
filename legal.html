Notices and licences

Reelign is a free Windows app for renaming TV and movie files. This page says what it contacts, where its data comes from, and which other people's work it uses.

Status

Reelign is in public beta. The download is a portable ZIP on GitHub Releases. The build is not code-signed, so Windows SmartScreen may warn when it is first run.

What Reelign contacts, and what it keeps

  • TV lookups are sent to TVmaze (no key needed). The request contains the show title the app extracted from a file name.
  • Movie lookups are sent to TMDB and use the user's own TMDB API Read Access Token. The request contains the movie title and year.
  • Poster images are downloaded from TVmaze's image server (static.tvmaze.com) and TMDB's image server (image.tmdb.org) for the posters shown in the app, and cached on your PC.
  • Nothing else. The app has no analytics, crash reporting, update checks or accounts. Your queue, rename history, settings and the metadata cache stay on your PC in %LOCALAPPDATA%\Reelign.
  • The TMDB token is kept in memory for the session unless the user chooses to remember it; it is then protected with Windows data protection for that account.
  • This website loads its fonts and scripts from its own server. It sets no cookies. It uses anonymous, cookie-free analytics (GoatCounter) to count visits, traffic sources (the ?ref= tag in a link) and download-button clicks; it does not track you across sites and the data is not sold. A button click shows interest only, not a completed download. GitHub, which hosts this site, keeps its own server logs.

Data sources

TVmaze. TV metadata is provided by TVmaze and is licensed under CC BY-SA 4.0. No endorsement by TVmaze is implied. The app credits TVmaze in its About screen.

TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB. Movie metadata comes from The Movie Database.

Show and movie names that appear in screenshots and videos are used only as examples of file names on disposable test files. No posters, artwork, clips or other media from those titles are shown.

Open questions

TMDB (terms last updated 20 Oct 2023; FAQ 2025):

  • Commercial or not: the API is free only for non-commercial use, and TMDB decides "in its sole discretion". Free distribution and a donations link are not addressed. Unresolved; ask TMDB in writing.
  • Logo: the terms say the TMDB logo must identify use of TMDB and the notice must be "in or on" the application, and the FAQ says it belongs in an About or Credits section. The terms do not say whether a marketing website needs it. The site shows the notice text but no logo. Unresolved.
  • Notice wording: the terms and the FAQ give two different sentences. The app and this page use the shorter FAQ one. Unresolved which controls.
  • Caching: TMDB prohibits caching content for longer than 6 months and bars "derivatives". Reelign caches metadata and poster images locally and writes optional NFO files; no expiry was found in the app. Whether local copies and NFO files count is not stated. Unresolved, and possibly an app change.
  • The incorporated TMDB general Terms of Use were not read.

TVmaze:

  • Credit is satisfied by linking back to TVmaze. The Creative Commons deed also asks for a licence link and a note of changes; this page links the licence.
  • ShareAlike: TVmaze does not say whether locally cached data, NFO files or transformed metadata are adaptations, or what licence they must carry. Unresolved.
  • Images: the API page does not state a licence for images and allows hotlinking and caching. Unresolved.
  • Limit: about 20 calls per 10 seconds per IP. Not yet checked against the app's behaviour.
